# miniguia-elnino-notebooklm
Este projeto dentro do curso de IA da DIO, visa investigar o fenômeno El Niño, explicando como ele se forma, o que determina sua intensidade e quais impactos climáticos provoca — no Brasil e no restante do mundo. Para isso, reúne fontes científicas, um mapa mental, um resumo em vídeo e uma apresentação de slides.
